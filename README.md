# MIM SIN FASHION Frontend

Angular 17 standalone application scaffold. Feature pages are route-ready placeholders; forms, tables, validation, permissions and API calls will be implemented incrementally.

## Feature pages

Dashboard, login, users, roles/permissions, employees, attendance, payroll, products, categories, inventory, suppliers, procurement, POS, sales, returns, finance, reports and settings.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm start`.

The backend API base URL and authentication flow will be connected in a later step.
